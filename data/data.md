# Dataset

## Overview

This project uses the **Predicting Road Accident Risk Dataset**, provided as part of the Kaggle Playground Series - Season 5, Episode 10.

The dataset focuses on predicting the likelihood of road accidents based on different road-related features. It is designed for regression-based machine learning tasks, where the objective is to estimate the accident risk associated with each record.

## Dataset Source

The dataset is available on Kaggle:

**[Predicting Road Accident Risk – Kaggle Competition](https://www.kaggle.com/competitions/playground-series-s5e10/overview)**

## Download Instructions

1. Visit the Kaggle competition page using the link above.
2. Sign in to your Kaggle account.
3. Join the competition and accept its rules if required.
4. Navigate to the **Data** section.
5. Download the available dataset files.
6. Extract the downloaded files and place them inside this directory.

## Notes

- The dataset is not included in this repository.
- Users must download the dataset directly from Kaggle before running the project notebooks or scripts.
- The target variable is `accident_risk`.
- Model predictions are evaluated using Root Mean Squared Error (RMSE).
